Kanzo is a lightweight, self-hosted kanban board shipped as a single binary with an embedded SQLite database.

- Boards with projects, tasks, tags, comments, image attachments and task dependencies.
- GitHub-style search and filters (`tag:`, `status:`, `is:waiting`...).
- MCP server on `/mcp` so AI agents can read and move tasks.
- Markdown and JSON export (`kanzo export`).
