Kanzo est un tableau kanban léger et auto-hébergé, livré sous la forme d'un seul binaire avec une base SQLite embarquée.

- Tableaux avec projets, tâches, étiquettes, commentaires, images jointes et dépendances entre tâches.
- Recherche et filtres à la manière de GitHub (`tag:`, `status:`, `is:waiting`...).
- Serveur MCP sur `/mcp` pour que des agents IA lisent et déplacent les tâches.
- Export Markdown et JSON (`kanzo export`).
